# Cognifyz Internship – Task 4
## Complex Form Validation and Dynamic DOM Manipulation

### 📌 Project Overview
This project is developed as part of my Cognifyz internship. It focuses on form validation, dynamic DOM manipulation, and client-side routing using HTML, CSS, and JavaScript.

### 🎯 Features
- Validates name, email, and phone number.
- Checks password strength and password confirmation.
- Displays real-time error and success messages.
- Includes Show/Hide password functionality.
- Provides navigation between Home, Register, and About pages.
- Responsive and user-friendly design.

### 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Live Server


### ▶️ How to Run
1. Open the project folder in VS Code.
2. Install the Live Server extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
5. Test the registration form in your browser.

- Understood client-side routing.
